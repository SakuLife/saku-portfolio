2. お預かりする情報

  • ご相談・お問い合わせ・お申し込みのときにいただく、お名前・店名・連絡先・ご相談の内容
  • ご契約のときにいただく、請求やドメインの登録に必要な情報
  • 事業者さまへのご案内のために、インターネット上で公開されている店舗の情報（店名・業種・所在地・電話番号・営業時間・公開されているホームページの有無）

3. 使う目的

  • ご相談・お問い合わせへのお返事、お見積り
  • ご契約いただいたホームページの制作・公開・保守と、そのための連絡や請求
  • 事業者さまへの、郵便などでのサービスのご案内（ご案内のための見本づくりを含みます）
  • ご案内をお断りいただいた事業者さまに、二度とお送りしないための記録

この目的の外では使いません。

4. ご案内の停止

当方からのご案内が不要な場合は、下の連絡先へ一言お知らせください。以後はお送りせず、その旨を記録します。

5. ほかへ渡すこと

ご本人の同意がある場合と、法令にもとづく場合を除き、個人情報をほかの事業者へ渡しません。

なお、連絡や記録には外部のサービス（LINE・メール・ログインが必要な保存場所など）を使います。ホームページの制作・保守で、ドメインの登録やサーバーの手続きをするときは、その事業者に必要な情報を渡します。

6. 安全のための取り扱い

お預かりした情報は、ログインが必要な場所にだけ置き、業務に必要な者だけが扱います。要らなくなった情報は消します。

7. このサイトのアクセス解析など

このサイトでは、見られた回数を知るために Cloudflare Web Analytics を使っています（Cookie を使わない方式です）。また、表示のために次の外部の配信を使っており、ページを開いたときに IP アドレスなどがそれらの事業者に送られます。

  • Google Fonts（文字の形）
  • Tailwind CSS の配信（cdn.tailwindcss.com・見た目の部品）
  • cdnjs（Cloudflare・Font Awesome のアイコン）
  • jsDelivr（cdn.jsdelivr.net・業種別の見本の動きの部品）
  • Google マップ（業種別の見本に埋め込んだ地図。地図の所まで見た時に読み込みます）

8. 開示・訂正・削除などのご請求

ご自身の情報について、開示・訂正・削除・利用の停止をご希望の場合は、下の連絡先へお知らせください。ご本人であることを確かめたうえで、遅れずに対応します。

9. お問い合わせ先

LINE 公式アカウント、またはメールでご連絡ください。
